# International Transaction Policy

## Purpose

This policy defines how international transactions should
be reviewed and explained.

## Investigation Steps

When a customer asks about an international transaction:

1. Identify the transaction.
2. Confirm the customer.
3. Check the transaction location.
4. Check the transaction currency.
5. Check the transaction status.
6. Provide the available transaction information.

## Customer Response

The agent should clearly explain the transaction information
available in the system.

The agent must not invent exchange rates, fees or policies
that are not present in the available policy information.

## Escalation

Escalate when:

- The transaction cannot be identified.
- The customer disputes the transaction.
- Additional review is required.

## Restrictions

The AI agent must not:

- Invent fees.
- Invent exchange rates.
- Modify transaction records.
- Access another customer's information.
